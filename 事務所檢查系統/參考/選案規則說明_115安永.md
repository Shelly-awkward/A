# 115年度事務所檢查 選案模組（v1）— 規則說明與操作

產出日期：2026-09-10　　腳本：`select_cases.py`　　輸入：`選案參數_115安永.xlsx`　　輸出：`115年度_安永_選案工作表.xlsx`

## 一、流程（四段）

```
① 選案表輸入        選案參數_115安永.xlsx（參數／前次檢查個案／指定名單／實質審閱名單／內部訊號／事務所檢查紀錄／會計師所別覆寫）＋ 四大會計師事務所會計師名冊_20260910.xlsx（會計師→所屬分所）
② 事務所選取規則    全市場 auditor 快照 → 各所簽證公開發行公司家數 → ≥100家每2年、10–99家每6年、<10家視需要 → 對照前次檢查年度 → 本年度應檢查者
③ 個案公司篩選規則  母體（安永 298 家）→ 排除 → 風險排序（官方權數＋內部訊號加分）→ 地域分配（台北/桃園/新竹/台中/台南/高雄六所）→ 指定納入
④ 產出選案清單      母體評分清單（每條規則一欄）、建議名單 15 家＋備選 10 家、簽呈段落草稿、會計師所別對照
```

資料來源沿用既有產線：`114Q4_選案清單_安永.xlsx`（母體）、`114Q4權數表(本國上市上櫃公司)_SFB.xlsx`（官方分數，直接讀「114Q4上市上櫃合併」工作表，1,825 家分項加總＝合計零誤差）、`安永114客戶_確信總表.csv`（永續／溫室氣體確信重疊）。
不再依賴選案清單內的 INDEX+MATCH 公式（Drive 預覽下為空白），分數改由腳本自權數表取值並自行勾稽。

## 四、送簽前必須人工確認的兩件事

1. **實質審閱名單**：向證交所／櫃買中心取得 114 年度財報實質審閱名單後填入「實質審閱名單」工作表重跑，名單上的公司會自動排除，再把「目標家數」改回 8。
2. **金融業判定**：以簡稱關鍵字及證券期貨商雙申報判定（台新新光金、宏遠證、大展證、德信等已排除）；請掃一眼「排除事由」欄有無誤殺或漏網。
名冊查無的會計師（劉慧媛、涂清淵）仍以客戶所在地推定，於「會計師所別對照」工作表可見依據。

## 五、重跑方式

```
python select_cases.py                     # 同資料夾放好四個輸入檔＋參數檔
python select_cases.py --params 選案參數_115安永.xlsx --out 115年度_安永_選案工作表.xlsx
```
需要套件：openpyxl。改任何規則只改參數活頁簿，不改程式；程式內僅保留欄位索引與文字對照表。名冊檔放同資料夾即自動讀取（取檔名最新者）。
