# 個案檢查表 輸入→產出 雛型（v0.1，2026-09-10）

## 檔案
| 檔案 | 用途 |
|---|---|
| `render_case_docs.py` | 主程式：`init` 建輸入活頁簿、`render` 產出 Word／Excel |
| `items_chk2_115.py` | 檢查表二（115年版）題庫，31 題 4 章，逐列自原 .doc 轉錄 |
| `templates/檢查表一_115.docx` | 原檔（品質管理制度檢查表），直接套用 |
| `templates/AML評量表_115_範本.docx` | 原檔（115年度AML現地檢查評量表），直接套用 |
| `templates/彙總表_空白範本.xlsx` | 114 年缺失分類彙總表空白版，直接套用 |
| `個案檢查_輸入_115安永.xlsx` | 已自選案工作表帶入 15 案的空白輸入檔（正式用） |
| `個案檢查_輸入_示範.xlsx` ＋ `out_demo/` | 奇鋐填了 31 題＋2 筆個案缺失、1 筆品質缺失、AML 3 項的示範與其產出 |

## 用法
```
pip install python-docx openpyxl
python render_case_docs.py init --selection 115年度_安永_選案工作表.xlsx      # 只做一次；改案子就重跑
python render_case_docs.py render --input 個案檢查_輸入_115安永.xlsx --out out
```
輸出：`檢查表二_<代號><簡稱>.docx`（每案）、`缺失三欄式對照表_<代號><簡稱>.docx`（有個案缺失者）、`檢查表一_<事務所>.docx`、`AML評量表_<事務所>.docx`、`缺失分類彙總表_<年度><事務所>.xlsx`、`缺失申報站匯入.csv`。

## 輸入活頁簿怎麼填
- **個案主檔**：代號／簡稱／會計師已帶入，補公司全名、底稿冊數、設立與上市櫃日期、主要營業項目、覆核者與日期（三欄式對照表抬頭用）。
- **檢查表二作答**：15 案 × 31 題已展開；只填「本局審查意見」（下拉 V／✗／NA）與「底稿索引」。✗ 的題目到「缺失」表寫一筆並填對應題號。
- **檢查表一作答**：每個 □ 一列（含子項），是／否／不適用擇一填 V，說明寫「說明及發現」，程式會把該 □ 改成 ■。
- **AML作答**：逐項正常／異常擇一填 V；「綜合結論」「評估意見」列直接寫說明欄。
- **缺失**：個案與品質缺失同一表；「缺失分類」下拉與彙總表類別一致，彙總表自動分組、編項次、合計；同一筆也輸出成缺失申報站匯入 CSV（year/type/firm/companyCode/company/content/localCategory）。

## 已知限制（下一版）
1. 檢查表二與三欄式對照表因原檔為 .doc，版面係重建（標楷體、A4、欄寬 10.6/2.2/4.4 cm；三欄式為橫式），非逐字元複製原檔格式；若有 .docx 原檔可改為套用。
2. AML 評量表中「正常／異常」合併為一格的表（A.3、A.5、B.6），以「■正常　□異常」文字標示；分格的表（A）則在對應格填 V。客戶審查抽樣表（表 8、9）未納入。
3. 總結會議紀錄待範本到位後加入；檢查表一底稿版（8 表、查核情形欄）可由「檢查表一作答」的說明欄帶入，尚未實作。
4. 這是 Excel 輸入版；改成 Apps Script 表單時，四張作答表即為試算表 schema，程式不變。
