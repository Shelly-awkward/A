## 唯一需要人／AI 動腦的一步：PDF 判讀

**問題**：確信報告的出具者（是安永？是 SGS？）只寫在 PDF 裡，申報系統的結構化欄位沒有這個資訊。而且其中約四成是純掃描影像，抽不出文字（這台機器沒有 OCR）。

**已完成的部分**：2026-08-06 那次已判讀 77 份，結果寫在 `ghg_verdicts.py`，一家一行：

```python
"5225": ("安永聯合會計師事務所", "cpa", "EY 抬頭「東科控股股份有限公司溫室氣體聲明會計師有限確信報告」"),
"2504": ("立恩威國際驗證股份有限公司（DNV）", "verify", "溫室氣體排放量查驗意見書；查驗準則含金管會永續發展路徑圖"),
```

三個欄位＝出具者全名、類型、佐證原文。
類型代碼：`cpa` 會計師事務所／`consult` 事務所體系顧問公司／`verify` 驗證查驗機構／`unknown` 未具名。

**這 77 家不用重做。** 只有新增的公司要補。

### 給 AI 的判讀步驟

```bash
# 找出哪些有 PDF 但還沒判讀
python -c "
import json,sys; sys.stdout.reconfigure(encoding='utf-8')
from ghg_verdicts import VERDICTS, FAILED
tg=json.load(open('ghg_targets.json',encoding='utf-8'))
todo=[t for t in tg if t['code'] not in VERDICTS and t['code'] not in FAILED]
print(f'待判讀 {len(todo)} 家:'); [print(' ',t['code'],t['name']) for t in todo]
"
```

對每一家：

1. 先試抽文字 — `ghg_extract.json` 裡 `note` 欄為空的表示抽得到字，直接看 `text` 的抬頭與簽章段落
2. 抽不到字（`note` = 「純掃描影像，需視覺判讀」）— 用 PyMuPDF 把第 1 頁渲染成 PNG 再用眼睛看：

```python
import fitz
d = fitz.open('ghg_pdf/XXXX_公司名.pdf')
pg = d[0]; pg.get_pixmap(matrix=fitz.Matrix(1400/pg.rect.width, 1400/pg.rect.width)).save('ghg_png/XXXX.png')
```

3. 抬頭沒有事務所名時，翻到最後幾頁找簽章（3416 融程電就是這樣，名字在第 3 頁）
4. 把結論加進 `ghg_verdicts.py` 的 `VERDICTS`
5. 有疑義的（上傳錯檔、舊年度、AUP 不算確信…）加進 `FLAGS`

### 判讀時要留意的坑（上次踩過的）

- **上傳錯檔**：6907 雅特力的 SGS 意見書內文寫的是「智原科技」、8424 惠普的 DNV 意見書內文寫「國產建材」。要核對 PDF 內的公司名和股號對不對得上。
- **舊年度**：6152 百一傳的是 113 年度、6446 藥華藥的數據期間是 2024/01/01~2024/12/31。要看數據期間。
- **AUP 不是確信**：6703 軒郁傳的是 BSI 的議定程序報告，文件明示 "do not express any assurance"，不能計為確信或查證。
- **傳錯文件類型**：2449 京元電子、6426 統新、9906 欣巴巴 傳的是盤查報告書而不是確信報告，機構名要另外從內文找，找不到就記 unknown。
- **事務所 vs 顧問公司**：1721 三晃是「資誠普華綠色科技有限公司」，PwC 體系但不是會計師事務所本體，類型要標 `consult` 不是 `cpa`，獨立性意涵不同。
