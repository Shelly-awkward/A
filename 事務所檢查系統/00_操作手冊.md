# 事務所檢查系統 操作手冊（v1.0，2026-09-10）

平時完全不需要 AI。流程三步，本機兩個 .bat，中間多人輸入用 Apps Script 網頁表單。
AI 只在「每年題庫或規則改版」時用來改 `bin/` 裡的程式或 `templates/` 範本。

```
[1] 1_選案.bat ──→ output\115年度_安永_選案工作表.xlsx（建議選案、簽呈文字）
        │  複製「建議選案」貼進網頁表單「設定／匯出 → 匯入個案」
[2] 網頁表單（Apps Script，accsfb01 試算表）：同仁各填各案 → 「匯出 xlsx」 → 下載到 input\
        │  （沒有網頁表單時：2_建立檢查輸入檔.bat 產生同格式 Excel，輪流填）
[3] 3_產出檢查表.bat ──→ output\檢查表產出\  檢查表二×每案、三欄式對照表、檢查表一、AML評量表、缺失分類彙總表、缺失申報站匯入.csv
```

## 在 Mac 上（專案控管機：2017 MacBook Air）
- 安裝 Python 3.11：python.org 的 macOS 安裝檔（2017 Air 跑 macOS 12/13 都可）；或 `brew install python@3.11`。
- 第一次：雙擊 `0_首次設定_mac.command`（解除隔離、設定可執行、安裝套件）。若系統擋「無法打開」，對檔案按右鍵 → 打開 一次即可。
- 之後：`1_選案.command`、`2_建立檢查輸入檔.command`、`3_產出檢查表.command` 對應 Windows 的三個 .bat，功能相同；產出完會自動開啟 output/檢查表產出。
- 版本控管：`git pull` 取最新、自己改的 `git commit` / `git push`；程式與參數都在 repo，產出 output/ 不進版。

## 每年度作業
1. **準備 input\**：listdata 跑 `run_all.ps1` 產生 auditor 快照後，用既有 `make_selection_list.py` 產生 `<季>_選案清單_<事務所>.xlsx` 與 `_全市場.xlsx`；下載證交所／櫃買權數表合併成一檔（工作表名含「合併」）；更新會計師名冊；複製上一年的 `選案參數_*.xlsx` 改年度、事務所、前次檢查個案、指定名單。
2. **選案**：雙擊 `1_選案.bat`。看 output 選案工作表的「建議選案」「排除事由」「事務所檢查週期」。要調規則只改參數檔再跑一次；拿到實質審閱名單後填入參數表重跑。
3. **開表單**：試算表「人員」工作表填同仁姓名；「設定／匯出」填事務所、年度；把「建議選案」整段貼進「匯入個案」。
4. **外勤輸入**：每人開網頁選自己的案，逐題按 V／✗／NA、填底稿索引；✗ 的題按「新增本題缺失」；品質與 AML 在各自分頁；缺失分頁可編輯刪除。每一下都即時存進試算表，多人同時填不會互相蓋掉。
5. **產出**：表單「匯出 xlsx」→ 雲端硬碟「檢查輸入匯出」→ 下載放 `input\` → 雙擊 `3_產出檢查表.bat`。Word／Excel 在 `output\檢查表產出\`。
6. **監理報告／IFIAR**：表單「同步缺失到缺失申報站」把缺失推進同一試算表的 findings 工作表（缺失申報站），再到申報站補 IFIAR 主題與子類別。

## 網頁表單部署（一次）
1. 用 accsfb01 建新 Google 試算表 → 擴充功能 → Apps Script。
2. 建立四個檔案並貼上 `apps_script\` 內容：Code.gs、Index.html、Seed.gs；專案設定勾「顯示 appsscript.json」後貼上 appsscript.json。
3. 執行 `setup()` 一次（授權）。會建立：個案主檔、檢查表二作答、檢查表一作答、AML作答、缺失、事務所、題庫二、人員。
4. 部署 → 新增部署 → 網頁應用程式 → 執行身分「我」、存取「任何人」→ 把網址給同仁。
5. 若缺失申報站也放在同一試算表（工作表名 findings），同步功能即可用。

## 改版時（唯一需要 AI 或懂 Python 的時候）
- 檢查表二換版：改 `bin\items_chk2_115.py`（另存為 116）→ `python bin\make_seed.py` → 更新 Seed.gs 重新部署。
- 檢查表一／AML／彙總表換版：新檔放 `templates\116\`；欄位結構相同就不用改程式。
- 選案規則：只改 `input\選案參數_*.xlsx`；新增規則才改 `select_cases.py`。

## 常見問題
- 「找不到 python」：安裝 Python 3.10+ 時勾 Add to PATH。
- 選案報「權數表勾稽失敗」：交易所改了欄位，請 AI 依 `select_cases.py` 開頭索引（65/83/84/85）調整。
- 產出的 Word 打不開：input 的 xlsx 不是從表單匯出或 2_ 產生的（工作表名稱／欄位不符）。
